# 取结果

## 数从哪里来

`ans run` 求解成功后自动取一次结果；之后要换组件再取用 `ans rst <job> --comp 组件名`（可写多个 `--comp`）。
数字是 MAPDL 自己从结果文件（`.ans\<job>\run\<job>.rst`）里取出来的，写在 `.ans\<job>\run\summary.json`。
汇报里的数都从这里来，不要心算代替。

**多个载荷步**（静力、瞬态）：主摘要默认取最后一个结果集；每个载荷步末（该步最后一个子步）的结果另外全部列出（`steps`）。
要让主摘要（含组件应力）取某一步，用 `ans rst <job> --step N --comp 组件名`。`main` 写明主摘要取的是哪个载荷步、子步、时间。

## ans rst 给出什么

| 项目 | 说明 | summary.json 的键 |
|---|---|---|
| 结果集 | 每个结果集的载荷步、子步、时间、频率 | `sets[i].step / substep / time / freq` |
| 主摘要取的结果集 | 静力、瞬态：最后一个结果集，或 `--step N` 那一步的末尾；模态、屈曲：第一阶 | `main.step / substep / time` |
| 最大位移 | 主摘要那个结果集；模态、屈曲取第一阶振型（已归一化，只看形状） | `umax.value / node / u / xyz` |
| 反力合计 | 静力、瞬态：全部约束节点的反力之和（主摘要那个结果集） | `reaction.FX / FY / FZ` |
| 各载荷步末 | 静力、瞬态有多个载荷步时：每一步末的反力合计、最大位移、最大等效应力和 `--comp` 组件的各项（含应力） | `steps[i].step / substep / time / reaction / umax / seqv / comps` |
| 组件 | `--comp` 给的组件：节点数、节点力合计 FSUM、组件内最大位移及节点 | `comps.名字.nodes / fsum / umax / node` |
| 组件上的应力 | 静力、瞬态：`--comp` 给的组件上 SX、SY、SZ、SEQV 的最大值、最小值和所在节点（节点平均，总体坐标；壳是顶面；单元组件只在自己的单元里平均；梁、杆单元没有节点应力，这一项是 null） | `comps.名字.stress.SX.max / maxNode / min / minNode`（SY、SZ、SEQV 同样） |
| 最大等效应力 | von Mises，节点平均，全模型 | `seqv.value / node` |
| 频率 | 模态：各阶频率（Hz）；屈曲：各阶载荷因子 | `sets[i].freq` |
| 振型方向 | 模态、屈曲：前 50 阶每一阶全模型 |UX|、|UY|、|UZ| 的最大值，以哪个方向为主（振型已归一化，只比相对大小；梁、壳的扭转振型主要是转角，从平动分量看不出来） | `modes[i].mode / freq / umax / dominant` |
| 谐响应 | 每个频率点的最大位移幅值 | `amplitude[i].freq / umax / node` |
| 应力线性化 | 静力、瞬态：`--lin` 给的每条评定线（见下面一节） | `lin[i].name / nodes / xyz / snap / length / membrane / mb / peak / total` |

## 某一处的结果：先在建模里建组件

要「端部中点的挠度」「支座的反力」，就在建模命令流里把那几个节点建成组件（`NSEL` 按坐标选 + `CM`），再 `ans rst <job> --comp 组件名`：
- 组件内最大位移 `comps.名字.umax`（位移的合量 USUM）。
- 节点力合计 `comps.名字.fsum`：是单元作用在这些节点上的力的合计。在约束节点上与支座反力大小相等、方向相反；在加载节点上与外载荷大小相等、方向相反（端部加 FY 合计 -2000 N 时，加载组件的 fsum 是 +2000）。
- 组件上的应力 `comps.名字.stress`：要「某个截面的弯曲正应力」，就把这个截面（或它最外一排）的节点建成组件，看沿梁轴方向的正应力（梁轴沿 X 就看 SX）。全模型的 `seqv` 是等效应力，不是正应力，位置也不一定在你要的截面上。

## 应力要小心的地方

- **全约束面和集中力附近的节点应力不能当截面应力报。** 把整个端面全约束（`D,组件,ALL,0`）会挡住泊松收缩，端面角点的应力随网格加密一直变大（奇异）。实测一根实体悬臂梁：根部截面顶面的 SX 换单元、换网格，在梁理论值的 -4% 到 +41% 之间乱跳；离开根部一段的截面上，增强应变 SOLID185 和 SOLID186 都和 M·c/I 相差 0.1% 以内。所以离开约束面一段取截面应力，和 M·c/I 比，再按弯矩线性外推到根部。
- **SOLID185 默认（KEYOPT(2)=0）的外表面一排节点，弯曲应力偏低。** 同一根梁、截面高度分 8 层时，离开根部的截面上顶面 SX 比梁理论低 5%（分 16 层时低 2.7%），中间各层节点都准。要表面应力准就用 `KEYOPT,1,2,2`（增强应变，同样网格误差在 0.01% 以内）或 SOLID186，或者加密一次对比。
- 应力、接触压力这类对网格敏感的量，至少加密一次确认变化不大再报。
- **没有倒圆的拐角（比如接管和壳体外表面相交的尖角）是奇异点**：那里的节点应力随网格加密一直变大，全模型最大的 SINT / SEQV 常常就落在那里。这个最大值不能直接拿来评定；压力容器按应力分类评定时用沿壁厚线性化的值（下一节），线性化的薄膜、薄膜+弯曲随加密是收敛的。

## 应力线性化（压力容器分析设计）

```
ans rst <job> --lin SCL1:x1,y1,z1,x2,y2,z2 --lin SCL2:...
```

沿评定线（应力分类线，SCL）做 MAPDL 的 `PRSECT`，`ans run` 也接受 `--lin`。最多 10 条，名字可省（默认 SCL1、SCL2…），坐标用模型的单位。

- **端点**：工具取离给定两点最近的节点当端点，打印节点号、坐标、离给定点多远。离得远（超过评定线长的 5%）会打出 ⚠，那一条的数不能用。端点放在**几何棱边或顶点**上（比如对称面和内、外表面的交线，相贯线），那里一定有节点；否则加密网格。
- **评定线**要整段穿过材料：起点在一个表面、终点在对面的表面，中间不出模型；尽量和壁的中面垂直。
- 在主摘要那个结果集上算（默认最后一个结果集，`--step N` 时第 N 步末）。
- 输出：薄膜（一组）、薄膜+弯曲、峰值（= 总应力 − 薄膜+弯曲）、总应力（起点、终点各一组），每组有分量和 **SINT（应力强度，最大主应力差，Tresca）**、**SEQV（von Mises）**。分量在总体坐标里；SINT、SEQV 和坐标系无关，评定用它们。PRSECT 只给 4 位有效数字。
- summary.json：`lin[i].membrane.SINT`、`lin[i].mb.I.SINT`（起点）/ `mb.O.SINT`（终点）、`total`、`peak`，`nodes`、`xyz`、`snap`（端点离给定点的距离）。

**评定线放哪**：最大应力在哪就在哪附近放，一处放几条取最不利的。
- 总体结构不连续处：接管和壳体相交处、封头和筒体连接处、支座处。常见的几条：穿过壳壁（紧挨着接管）、穿过接管壁（紧挨着壳体）、从内侧拐角到外侧拐角的斜线。开孔接管要在几个方位上都看（例如包含筒体轴线的截面和与它垂直的截面）。
- 远离不连续处再放一条，和公式比（圆筒环向薄膜 pR/t、闭口轴向 pR/(2t)，或厚壁的 Lamé 解），证明模型和载荷是对的。

**网格**：评定线穿过的壁厚方向至少 3～4 层二次单元（一次单元 6 层以上）。四面体（SOLID187）要在相交处加密：给相贯线和壁厚方向的线 `LESIZE`。

**分类和限值**（以任务书、规范为准）：远离不连续处的薄膜是一次总体薄膜 Pm；总体结构不连续处（接管、封头连接）的薄膜是一次局部薄膜 PL，弯曲是二次应力 Q；峰值是 F。常用的限值：Pm ≤ S，PL ≤ 1.5S，PL + Pb ≤ 1.5S，PL + Pb + Q ≤ 3S（S 是许用应力或设计应力强度）。JB 4732 用应力强度 SINT；ASME VIII-2（2007 版起）用 von Mises 的 SEQV。分类由你判断并在汇报里写明。

**已验证的例子**：`lin_cylinder.build.mac` + `.solve.dat`（闭口厚壁圆筒，内半径 0.1 m、外半径 0.12 m，内压 10 MPa，SOLID186 壁厚方向 8 层）。`ans run <job> --lin R0:0.1,0,0.05,0.12,0,0.05`：薄膜 SINT 和 Lamé 解的壁厚平均（54.55 MPa）、内表面薄膜+弯曲 SINT（64.48 MPa）都差 0.2% 以内；薄膜环向分量就是 pR/t = 50 MPa。

## 对比和核查

- 和第 2 步的估算比：静力看位移和反力合计（反力合计与外载荷合力大小相等、方向相反），模态看一阶频率，屈曲看第一阶载荷因子 × 加的载荷。
- 偏差超过 10% 先怀疑模型：网格太粗、单元选错、约束不对、单位制混用、F 写成了总力（F 是每节点值）。
- 收工前 `ans verify <job>`：核对求解正常结束、结果是不是现在这份 CDB 和求解段算出来的、批准记录、警告。结论不能是「不通过」。

## 出错时看哪里

- 求解失败：`ans run` 列出 MAPDL 的 ERROR 原文；全文在 `.ans\<job>\run\output.out`。
- 取数时报错：`.ans\<job>\run\post.out`。
- 这些文件可以直接读，不要改。

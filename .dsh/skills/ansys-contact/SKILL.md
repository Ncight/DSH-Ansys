# 接触与绑定

## 先决定用哪种连接

- 两个部件始终粘在一起、不关心界面滑移 → **绑定接触**（`KEYOPT(12)=5`，始终绑定），或者干脆共节点（划网格前 `VGLUE,ALL`）。
- 会脱开、滑移，或关心接触压力 → **标准接触**（`KEYOPT(12)=0`）加摩擦系数。
- 相邻部件之间什么都不定义 = 没有连接，各算各的。`ans check` 的体检会报「两块实体网格贴着却没连上」。

## 接触对的建法（已验证）

`contact_pressed.build.mac`：小块压在大块上，标准接触、摩擦系数 0.2。关键几行：

```
ET,2,TARGE170
ET,3,CONTA174
KEYOPT,3,12,0          ! 接触行为：0 标准（可分开、可滑移）
MP,MU,2,0.2            ! 摩擦系数放在接触单元用的材料号上
R,3                    ! 一对接触用同一个实常数号配对
...
VSEL,S,VOLU,,1         ! 目标面：下块的上表面
ASLV,S
ASEL,R,LOC,Z,0.5
NSLA,S,1
TYPE,2
MAT,2
REAL,3
ESURF                  ! 在选中节点所在的单元外表面上生成目标单元
ALLSEL,ALL
VSEL,S,VOLU,,2         ! 接触面：上块的下表面，同样的 MAT 和 REAL
...
TYPE,3
ESURF
ALLSEL,ALL
```

- 预览面板把它显示成「接触 REAL 3」，写明行为和摩擦系数；点它会高亮两侧。
- `KEYOPT(12)`：0 标准、1 粗糙（不滑移）、2 不分离、3 绑定、4 始终不分离、5 始终绑定、6 初始接触处绑定。
- 一般让较硬、较大、网格较粗的一侧做目标面，较软、较小、网格较细的一侧做接触面。

## 让接触收敛

- 接触问题是非线性的：求解段里写 `NSUBST,2,10,1` 这样的子步数（`contact_pressed.solve.dat`）。
- 上块在接触闭合前没有任何约束会刚体位移：要么让它和下块一开始就贴着（几何上重合），要么在不影响结果的方向加约束（例子里约束了上块顶面的 UX、UY）。
- 结果核对：总反力要等于外载荷（例子里 2 MPa × 0.36 m² = 720000 N，实跑相差小于 1e-6）。

## 绑定（已验证）

`contact_bonded.build.mac`：同样的两块，`KEYOPT,3,12,5` 始终绑定。上块被往上拉（`SF,NTOP,PRES,-1.0E6`），拉力通过绑定面传到下块，基座反力 -360000 N，与外力平衡（实跑相差小于 1e-6）。换成标准接触，这个模型会因为两块分开而算不下去。

## 预紧螺栓

用 `PSMESH` 在螺杆上切预紧截面，求解段里 `SLOAD` 加预紧力（skill `ansys-solve-segment` 的 `bolt` 例子）。
